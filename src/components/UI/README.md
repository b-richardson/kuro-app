# UI Components

This directory contains shared UI components used throughout the application.

## Components

- `ConfirmationDialog.vue` - Reusable confirmation dialog
- `GradientBackground.vue` - Background gradient component
- `PrimaryButton.vue` - Primary action button
- `ScrollContainer.vue` - Scrollable container with custom styling
- `ToastNotification.vue` - Toast notification component (placeholder for future implementation)

## Purpose

These components provide consistent UI elements across the application, implementing the design system and ensuring a uniform user experience.
