# Module Library Components

This directory contains components related to the template module library shown in the sidebar.

## Components

- `TemplateModuleLibrary.vue` - Main component for browsing available modules
- `ModuleCard.vue` - Card displaying a module that can be added to the template
- `BasicModules.vue` - Basic markdown modules (text, header, etc.)
- `PluginModules.vue` - Plugin-specific modules (Dataview, Templater, etc.)

## Purpose

These components make up the module library interface, allowing users to browse and add different types of modules to their templates.
