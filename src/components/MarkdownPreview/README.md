# Markdown Preview Components

This directory contains components related to previewing and exporting templates as markdown.

## Components

- `MarkdownPreview.vue` - Shows a live preview of how the template will look in markdown
- `DownloadMarkdown.vue` - Handles downloading the template as a markdown file

## Purpose

These components provide the preview functionality in the right pane of the editor, allowing users to see how their template will look in Obsidian and to download their templates.
